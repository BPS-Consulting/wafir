## Wafir – The Web App Feedback and Issue Reporter

**Capture user feedback directly in GitHub.**

### ✨ Key Features

- **One-Click Feedback** – Embedded widget lets users report bugs, request features, or share feedback without leaving your app
- **Automatic Screenshots** – Captures exactly what users see, eliminating "it looks fine on my machine" conversations
- **Console Logs & Telemetry** – Browser info, errors, and context travel with every submission
- **GitHub-Native** – Feedback routes directly to Issues or Projects—no third-party dashboards to check
- **Multi-Target Routing** – Send bugs to one repo, feature requests to another, feedback to a project board
- **Customizable Forms** – Match your brand with CSS variables; configure fields via simple YAML
- **Framework Agnostic** – Works with React, Vue, vanilla JS, or any web app via CDN

### 🎯 Benefits

| For Teams                                        | For Users                       |
| ------------------------------------------------ | ------------------------------- |
| Debug faster with full context                   | Report issues in seconds        |
| Keep feedback organized in GitHub                | No signup or external tools     |
| Triage in Projects, convert to Issues when ready | See exactly what gets submitted |
| Self-host or use managed service                 | Lightweight, non-intrusive      |

### 📦 Get Started in Minutes

```html
<script
  type="module"
  src="https://wafir-all.s3.us-east-2.amazonaws.com/wafir/latest/wafir.js"
></script>
<wafir-widget config-url="/wafir.yaml"></wafir-widget>
```

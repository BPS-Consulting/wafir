Wafir Issue Reporter

Chrome Extension Settings

When enabled, the Wafir widget is injected into every page you visit.

GitHub Credentials

A GitHub PAT with the repo scope. This token is used to create issues on your behalf. Generate one at github.com/settings/tokens.

Wafir Configuration

An HTTPS URL pointing to your Wafir YAML or JSON configuration file (e.g. a raw GitHub Gist or hosted file). The file must be publicly accessible.

Screenshot Uploads

⚠️ Screenshot Privacy Warning

Screenshots are uploaded to ImgBB and expire after 5 minutes. Do not take screenshots of sensitive information such as passwords, personal data, or confidential documents.

Optional. When provided, screenshots taken with the widget are uploaded to ImgBB (free tier available at api.imgbb.com) and embedded in the GitHub issue. Leave blank to skip screenshots.
